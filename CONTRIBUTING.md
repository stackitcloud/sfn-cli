# Contribute to the STACKIT Functions CLI

Thank you for your interest in growing our shared library.

At the moment, we do not accept code contributions for our STACKIT Functions Command Line Interface.

## Bug Reports

Because we operate on a "best-effort" basis, we heavily rely on you to report bugs. If you find a bug, please open a GitHub issue.

When opening an issue, please provide as much context as possible:
- Which command or functionality is broken?
- What error message did you receive?
- What version of the STACKIT Functions CLI are you using?
- Include code snippets of how you called the CLI. This makes the reproduction process much easier.
